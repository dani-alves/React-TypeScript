# 🚀 Curso React TypeScript - Fase 3

Projeto de aprendizado com React, TypeScript, Vite e ferramentas modernas.

## 📚 Conteúdo

- **Aula 23**: Zustand (State Management Global)
- **Aula 24**: React Hook Form + Zod (Formulários com Validação)
- **Aula 25**: Vitest (Testes Unitários)
- **Aula 26**: Vercel Deploy

## 🛠️ Tecnologias

- React 18
- TypeScript
- Vite
- Zustand
- React Hook Form + Zod
- Vitest
- Tailwind CSS

## 🚀 Como Rodar Localmente

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Rodar testes
npm run test

# Build pra produção
npm run build
```

## 📦 Projetos Inclusos

- **Carrinho de Compras**: Zustand + TypeScript
- **Formulário de Registro**: React Hook Form + Zod
- **Testes Unitários**: Vitest com funções matemáticas

src/
